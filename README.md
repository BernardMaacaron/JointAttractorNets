# JointAttractorNets
Dual implementations (Brian2 &amp; PyTorch) of attractor networks for robotic joint-space representation.

This repository hosts a neural network model implemented in two different platforms:
- **Brian2** (branch: [`brian2`](https://github.com/YourUsername/my-neural-project/tree/brian2-main))
- **PyTorch** (branch: [`pytorch`](https://github.com/YourUsername/my-neural-project/tree/pytorch-main))

## Branches

1. **docs**  
   - The default branch containing all project documentation.  
   - Browse the `docs/` folder for guides, references, and methodology.

2. **brian2**  
   - Contains code specific to the Brian2 implementation.  
   - Documentation is periodically merged/rebased from the `docs` branch.

3. **pytorch**  
   - Contains code specific to the PyTorch implementation.  
   - Documentation is also merged/rebased from the `docs` branch.
